# arbol-binario-de-busqueda
# Control de Inventario mediante Árbol Binario de Búsqueda (ABB)

Este proyecto es una aplicación de consola en Java desarrollada para la Estructuras de Datos. Simula un sistema de control de mercancía para un almacén utilizando la estructura de datos no lineal de Árboles Binarios de Búsqueda (ABB), donde el ordenamiento se rige alfabéticamente a través del nombre de los productos.
Con lo visto en clase realice el codigo y las ordenes de ejecucion se encuentra abajo

## Integrantes

## Especificaciones Técnicas
* **Lenguaje**: Java
* **Estructura Principal**: Árbol Binario de Búsqueda (ABB)
* **Llave de ordenamiento**: `String nombre` (utilizando el método `compareTo()`)
